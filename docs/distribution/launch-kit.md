# Movena launch kit

Paste-ready copy for the first public launch. Keep every post factual: Movena
is a player, not an IPTV provider, subscription service, or channel directory.

## One-line pitch

Movena is a free, open-source IPTV and VOD player for Windows, macOS, and Linux
with Xtream Codes, M3U/M3U8, XMLTV EPG, native libmpv playback, and a built-in
M3U editor.

## Show HN

**Title:** Show HN: Movena – an open-source IPTV/VOD desktop player for Xtream and M3U

**Body:**

I built Movena for people who already have authorized IPTV sources and want a
focused desktop client instead of a browser tab. It supports Xtream Codes and
M3U/M3U8 playlists, XMLTV EPG, Live TV, movies, series, native libmpv playback,
and a built-in M3U editor.

The app is free and GPL-3.0-or-later. Credentials and settings stay local; there
is no project account, media proxy, subscription, or bundled channel list.

Download: https://movena.frtx.cc/download  
Source: https://github.com/movena-app/movena  
Feedback: https://github.com/movena-app/movena/issues

1. Publish the GitHub release and verify every platform asset downloads.
2. Deploy the website commit and submit the sitemap in Google Search Console and Bing Webmaster Tools.
3. Post the Show HN copy, then the forum/social variants over the following week.
