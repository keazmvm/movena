# Roadmap

This roadmap communicates direction, not a promise or release schedule. GitHub
milestones and issues are the source of truth for work that has been accepted.

## Reliability and platform trust

- Expand packaged-desktop journeys around source lifecycle and update recovery.
- Complete verified Authenticode signing and Apple Developer ID notarization
  when project-held credentials are available.
- Continue hardening native playback teardown, resolver ownership, and recovery.

## Library and source quality

- Improve large-playlist editing, validation, and conflict recovery.
- Deepen multi-source category, guide, and metadata reconciliation.
- Make offline availability and transfer failures easier to understand.

## Accessibility and internationalization

- Maintain keyboard-only and screen-reader smoke coverage on every platform.
- Expand translations only with a review and fallback plan.
- Keep motion, density, and player controls usable at supported window sizes.

## Out of scope

Movena will not sell or bundle IPTV service, circumvent DRM, proxy user media
through project infrastructure, or add analytics that expose viewing activity.
