Native libmpv pipeline

Direct GPU video rendering via gpu-next. Zero webview decoding overhead, hardware acceleration (NVDEC, VA-API, VideoToolbox), HDR tone mapping, and microsecond audio/subtitle sync.

Multi-gigabyte playlists

Dedicated background Web Workers parse 500,000+ item M3U playlists and multi-day XMLTV guides without UI freezes, memory spikes, or dropped frames.

OS vault security

Zero tracking, zero plain JSON passwords. Source credentials stay encrypted directly inside Windows Credential Manager, macOS Keychain, or Linux Secret Service.
